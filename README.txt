BUYER AUDIT — THE REASONS I WOULD HAVE HESITATED
1. CRITICAL — The Signature stylesheet had replaced the original layout stylesheet. It styled elements but omitted the underlying grid, flex, spacing, reset and component layout rules. This could collapse the entire experience. Restored the original layout foundation and layered the Signature styling over it.
2. CRITICAL — The homepage category image rule used an important background shorthand that could override each tile's inline stock photo. Removed the conflicting shorthand so the intended photography appears.
3. CRITICAL — Every contact CTA pointed to a literal placeholder Instagram username. Replaced those links with the portfolio enquiry route. The studio email remains a single explicit configuration item because no real contact address was supplied.
4. HIGH — Demo forms silently did nothing. They now validate required fields and provide a clear, accessible preview-only response. The live form still requires a booking/CRM/email provider.
5. HIGH — Sample reviews looked like real endorsements. Removed fabricated names and quotes; the review cards now clearly show where genuine, approved feedback belongs.
6. HIGH — The $500/$800 package form wording could imply a working booking/order integration. Package wording now distinguishes form design from separately scoped integration.
7. HIGH — A turnaround claim was presented without a project-specific scope. Replaced it with a timeline confirmed in the written project plan.
8. MEDIUM — The $800 support promise was vague. Clarified that it covers minor content updates, while new features are scoped separately.
9. MEDIUM — Gallery backgrounds had no semantic image alternatives. Converted gallery tiles to real lazy-loaded images with caption-based alt text.
10. MEDIUM — Mobile navigation could be clipped horizontally. It now wraps cleanly on narrow screens.
11. MEDIUM — Keyboard users had no skip link. Added a visible-on-focus skip link to every page.
12. MEDIUM — Metadata and browser identity were inconsistent. Added theme color, Open Graph metadata and a custom favicon.
13. MEDIUM — Package pages did not make exclusions obvious enough. Added a visible scope note covering domain, hosting, paid assets, advanced integrations and third-party fees.
